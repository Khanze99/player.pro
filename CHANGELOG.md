# Changelog

### Features
- Профиль: фото (аватар с приватной раздачей и снятием EXIF), дата рождения, пол,
  рост и вес, показ своей почты, ролей в командах и даты регистрации.
- Онбординг: обязательный шаг выбора пола («не указывать» — допустимо).
- Рост и вес видны штабу только по согласию игрока (scope `body_metrics`).

### Tech debt
- Пересчёт `DailyMetric` вынесен из процесса API в Celery (брокер и result backend —
  Redis, отдельные логические БД). Ночной прогон ставит Celery Beat вместо asyncio-цикла
  в uvicorn — расписание переживает рестарт без пропуска суток. Пересчёт при сабмите
  wellness/RPE уходит в очередь после коммита; ответ на опрос отдаёт синхронный Readiness
  за день, полный ряд считает воркер. Ручной `POST /analytics/recalc` теперь возвращает
  `task_id`, статус — `GET /analytics/recalc/{task_id}`. Снято требование «один воркер
  uvicorn». Новые сервисы `worker` и `beat` в docker-compose. См. `docs/plan-celery-recalc.md`.


## [1.1] — 2026-09-03

### Features
- Брендинг: рантайм-кастомизация темы под организацию (цвета, логотип). Пока в
  ручном режиме — элементы (дизайн, логотип) готовит команда через сиды.
- Пользовательское соглашение и согласие на обработку данных при регистрации.

### Bugs
- Добавлены кнопки навигации «назад» на экранах.
- Поправлены мелкие несостыковки в расположении элементов на фронте.
- Нижний safe-area отступ на экранах онбординга (Android).

### Notes
- Текст пользовательского соглашения требует проверки юриста.

## [1.0] — 2026-08-21

### Features
- Аутентификация: вход по OTP на email, 4-значный PIN на устройстве, сессии по
  устройствам с отзывом, обновление токена.
- Организации и команды: создание клуба, команды, состав, командные роли (главный
  тренер, тренер, врач, спортсмен), локации команды.
- Приглашения: одноразовая ссылка с заданной ролью и сроком жизни, письмо
  приглашённому.
- Профиль: свой профиль и анкета, просмотр анкеты спортсмена штабом.
- Wellness: ежедневный опрос по шкале 1–10, карта боли, серии заполнений (streak).
- RPE: оценка нагрузки после тренировки, одна запись на сессию, история своя и по
  спортсмену.
- Аналитика: Readiness 0–100, ACWR с зонами (серый / зелёный / жёлтый / красный),
  availability за 90 дней, ночной пересчёт плюс обновление при сабмите.
- Дашборд тренера: статус состава на день, сводка по команде, алерты, список травм
  команды.
- Доступность и травмы: статусы доступности, карточки травм с обновлением,
  аудит-лог изменений.
- События: создание, редактирование, удаление, календарь, свои события и
  командные, отметка посещаемости.
- Питание: справочник продуктов (162 выверенных + 1 663 из Open Food Facts), поиск
  с ранжированием, сканер штрихкода, дневник по приёмам пищи, подсчёт калорий и
  БЖУ, цели, копирование приёма пищи, недавнее, свои продукты.
- Согласия: управление тем, что видит штаб.
