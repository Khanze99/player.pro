# План: круглая акцентная кнопка «Дом»/«Состав» в таббаре

Статус: **проектирование, код не начат.** Дата составления: 2026-10-24.

Дополняет `PlayerPro_TZ_final.md` — там описана «плоская навигация, у каждой
роли по 4 вкладки» (раздел 3), но ничего про акцентную кнопку главной вкладки.
Чисто визуальная правка таббара, пересечений с `docs/plan-*.md` нет.

Черновик обсуждён и подтверждён в артефакте
(`https://claude.ai/code/artifact/da5269ac-bc04-4013-86f8-123d93ca621c`).

## Решения, принятые в обсуждении 2026-10-24

- **Цвет уже решён системой брендинга — новой логики не пишем.** `useTheme()`
  (`mobile/src/theme/provider.tsx`) уже возвращает цвет организации
  (`th.brand`/`th.gradients.brand`) для команды и `defaultTheme.brand` (#2D8CFF,
  синий) для личного режима/до входа — это и есть «командный — клубный цвет,
  личный — синий» из запроса, механизм уже в проекте (`docs/plan-org-branding.md`).
  Новая кнопка просто берёт `th.brand`/`th.gradients.brand`, как и остальные
  акцентные элементы приложения.
- **Применяем и к игроку, и к штабу.** Это одна и та же вкладка `index`
  (`(tabs)/_layout.tsx`) — у игрока заголовок «Дом», у штаба «Состав», обе через
  один код пути. Разводить визуально круглую кнопку только для одной роли —
  лишняя развилка без причины: тот же компонент, та же вкладка.
  *Отклонено:* только для игрока — пользователь сам предположил «возможно и
  для тренеров», разводить без причины не стал.
- **Таббар полностью на своём рендере** (`tabBar` проп у `Tabs`), не точечная
  правка `tabBarIcon`/`tabBarStyle` у одной вкладки — круглая, крупнее других,
  приподнятая над линией бара кнопка в стандартной API `Tabs` не укладывается
  (`tabBarIcon` рисует только иконку внутри уже заданной сетки вкладок, не
  позиционирует вкладку отдельно от остальных).
- **Без вырез-нотча в баре** — круг просто лежит поверх плоской поверхности
  бара (приподнят `marginTop` в минус + тень), не прорезает контур бара. Проще
  в реализации, тот же визуальный эффект «кнопка выделена», что и у вырезанного
  варианта.
- **Выступ над линией бара — 14pt** (в черновике сначала было 24pt, пользователь
  попросил ниже).
- **Активна/неактивна — разные стили, не только цвет иконки.** На своей вкладке
  круг в полном градиенте (`th.gradients.brand`), белая иконка. На любой другой
  вкладке — приглушённый: фон `th.surface2`, обводка `th.border` (1px, не 3px
  кольцо активного состояния), иконка и подпись `th.textMuted`. Тот же смысл,
  что `tabBarActiveTintColor`/`tabBarInactiveTintColor` у обычных вкладок, но
  здесь меняется весь фон круга, не только иконка — иначе на неактивной вкладке
  яркий круг выглядел бы как «на ней и так уже находишься».
- **Остальные вкладки — через центр, по порядку регистрации**: что до `index` в
  массиве (сейчас — ничего, `index` зарегистрирован первым) и что после, делятся
  примерно поровну слева/справа от круга. Подпись («Дом»/«Состав») остаётся под
  кругом, тем же шрифтом/размером, что у остальных вкладок — единообразие важнее
  экономии места.
- **API `Tabs`/`tabBar` — проверить по докам Expo SDK 57 на шаге реализации**
  (`mobile/AGENTS.md`: «Expo HAS CHANGED» — читать версионные доки перед кодом),
  не угадывать по памяти на этапе планирования.

## Зачем

Сейчас все вкладки визуально одинаковы — ничего не подсказывает, что «Дом»/
«Состав» это главная страница, а не рядовая вкладка среди прочих. Крупная
акцентная круглая кнопка в центре — стандартный паттерн для «это сюда
возвращаться», плюс лишний повод подсветить клубный цвет на каждом экране, не
только там, где он уже есть (шапки, кнопки действий).

## Что уже есть

- `(tabs)/_layout.tsx` — `Tabs` из `expo-router`, вкладка `index` первая в
  массиве, заголовок через `isStaff`, иконка — `HomeIcon` в обоих случаях
  (не меняем — не просили).
- `useTheme()`/`ThemeProvider` — `th.brand`, `th.brandDark`, `th.gradients.brand`
  уже отражают цвет организации или дефолтный синий, без доп. работы.
- `components/Icons.tsx` — `HomeIcon` и остальные иконки вкладок, переиспользуем
  как есть.
- Паттерн приподнятого круглого элемента в проекте пока нет — `ReadinessRing`
  близко по духу (круг с акцентным цветом/свечением), но это не таббар-кнопка,
  самостоятельно верстать.

## Мобильный клиент

- Новый компонент `components/HomeTabBar.tsx` — кастомный рендер `tabBar` для
  `Tabs`: раскладывает обычные вкладки `flex-row` слева/справа, `index`
  («Дом»/«Состав») — абсолютно спозиционированный круг по центру, приподнятый
  на 14pt над линией бара. Активна: заливка `th.gradients.brand`, иконка
  `th.onBrand` (белая), подпись цветом `th.brand`. Неактивна: фон `th.surface2`,
  обводка `th.border` 1px, иконка/подпись `th.textMuted` — см. «Решения».
- `(tabs)/_layout.tsx`: `<Tabs tabBar={(props) => <HomeTabBar {...props} />} …>`
  — структура `Tabs.Screen` не меняется, меняется только то, как список вкладок
  отрисовывается.
- i18n — не требуется, подписи вкладок (`tabs.home`/`tabs.squad`) уже есть.

## Риски

- **Разная ширина экрана** → разное число вкладок слева/справа от круга
  (нутришн/история есть только у игрока, дашборд только у штаба) — раскладка
  должна одинаково хорошо выглядеть и при 3, и при 4 вкладках по сторонам,
  проверить оба случая визуально на шаге 4.
- **safe-area/высота бара** — приподнятый круг должен не вылезать за системные
  индикаторы на разных устройствах; `insets.bottom` уже учтён в базовой высоте
  бара, приподнятость круга считать от неё, не от экрана целиком.
